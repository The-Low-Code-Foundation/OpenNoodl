## The job

Turn Phase 41's engineering work into the artefact that unlocks four markets: **a truthful,
publishable accessibility conformance report for apps generated by NodeGX.**

Phase 41 owns the fix. This task owns only the claim — and Phase 41 specs twenty-two tasks and owns
no conformance report.

**Why it is worth a task of its own.** Accessibility is the binding procurement constraint in four
separate markets, and the requirement is for a *document*, not merely for compliant code:

| Regime | Standard | When it bites |
|---|---|---|
| UK public sector, incl. universities | **WCAG 2.2 AA** per current GOV.UK guidance | In force. A published accessibility statement is mandatory; GDS samples, EHRC enforces |
| US state &amp; local government, incl. public higher ed | WCAG 2.1 AA, ADA Title II | **26 April 2027** (pop. 50k+), 2028 below |
| US federal | WCAG 2.0 AA via 36 CFR 1194, into solicitations by FAR Subpart 39.2 | In force since Sept 2021 |
| EU | EN 301 549 → WCAG 2.1 AA | Via public-sector customers. ⚠️ **Not** via the EAA — Article 2's service list does not mention e-learning or educational software |
| NHS | DTAC — accessibility is the only *scored* section | ⚠️ Secondary sourcing only; **re-verify on an NHS page before relying on it** |

**And there is a competitive opening.** Articulate publishes a conformance report for Storyline 360
whose scope statement reads: *"This report evaluates Storyline 360 published learner output. Content
creation and editing features of the authoring application are outside the scope."* It also marks
**2.1.1 Keyboard — a Level A criterion — as only "Partially Supports"**, because drag-and-drop lacks
keyboard access. Meanwhile **Section 508 Chapter 5 governs exactly what that report excludes**: 504.2
(the tool must enable accessible content), 504.3 (it must *prompt* the author), 504.4 (accessible
templates). The market leader has no conformance claim for the thing federal procurement regulates.

The template is free and ITI membership is not required; DHS Trusted Tester training is free.

## Acceptance criteria

1. **A completed report for generated app output**, against WCAG 2.2 AA, Section 508 and
   EN 301 549 — using the current VPAT 2.5Rev editions, with "partially supports" used in its
   defined sense.
2. **Every "supports" claim is backed by a named test**, run against a real generated app, with the
   method recorded. A claim asserted from reading the source is not a claim.
3. 🔴 **The report is truthful, not favourable.** If a criterion fails, the report says so. A report
   that overstates is worse than no report — it converts a technical gap into a
   misrepresentation in a procurement process.
4. **A second report covering the authoring application against Section 508 Chapter 5 (504.2, 504.3,
   504.4)** — the gap Articulate leaves open. This is the differentiating half and should not be
   dropped for convenience.
5. **A published accessibility statement template** that a NodeGX user can adapt for their own
   deployed app, because the UK regulations place that duty on *them*.
6. **A re-verification of the DTAC claim from an NHS-hosted page**, or an explicit note that it
   remains unverified. It is currently secondary-sourced only.

## Traps

- 🔴 **Do not re-spec Phase 41.** ACC-001..ACC-022 own the focus ring, the anchor element, the
  operable Group, route announcement, the document shell, semantic defaults, the rule set and the
  agent's knowledge. If this task finds itself designing a fix, it has strayed.
- 🔴 **A report written against today's runtime would be false.** One ARIA attribute, zero `role=`,
  nine `outline: none`. There is nothing to claim yet. **This task is blocked, not merely sequenced.**
- 🔴 **`outline: none` is a regression, not a gap.** Removing the focus indicator without replacement
  fails WCAG 2.4.7 and, in 2.2, interacts with 2.4.11. Unlike missing ARIA it is a defect we
  introduced over browser defaults — worth saying plainly in the report's remediation notes.
- ⚠️ **Zero `role=` is survivable if the output is semantic.** Native `<button>`, `<nav>` and headings
  carry their own semantics; ARIA is a fallback for when they are absent. Do not let the report
  overstate the severity of that particular number and undersell the focus-ring one.
- ⚠️ **Do not claim EAA coverage either way.** Article 2 was read verbatim: e-learning and educational
  software are not listed. A consumer-sold course might land in scope as an e-commerce service, but
  no legal analysis confirming it could be verified.
