PROBE 4 — What a REAL Directus adapter would consume (introspection)
──────────────────────────────────────────────────────────────────────────────
User collections: articles, authors

  collection "articles":
    - id: type=integer interface=-
    - title: type=string interface=input
    - body: type=text interface=input-multiline
    - status: type=string interface=select-dropdown choices=[draft,published,archived]
    - rating: type=integer interface=input
    - featured: type=boolean interface=boolean
    - published_at: type=timestamp interface=datetime
    - author: type=integer interface=select-dropdown-m2o → FK authors
    - hero_image: type=uuid interface=file-image → FK directus_files

  collection "authors":
    - id: type=integer interface=-
    - name: type=string interface=input
    - email: type=string interface=input

→ This rich per-field metadata (type, interface, FK relations, enum choices)
  is exactly what "pick a table, see the fields" needs — and what UBA currently
  has no code to consume. This is the net-new work RUN-003 actually implies.
