**`Request` is where the category's real problem is**, and it is the same shape as the swallowed
failures elsewhere in the phase: a `catch {}` with an empty body. What makes this one worse than
most is where it sits — it is the **entry point of every cloud function**, so a malformed request
body produces a function that runs to completion on empty inputs and answers `200`.
