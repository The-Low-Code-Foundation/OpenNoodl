**The two `0/0` nodes are the finding the numbers hide.** `Component Inputs` and `Component Outputs`
report 100% documentation on zero ports, joining `Config`, `Globals`, `Component Children` and
`Repeater`'s siblings on NDA-005 §2's list. Their real ports come from the **Port Editor panel**,
which is a *third* dynamic-port mechanism beside `sendDynamicPorts` and `numberedInputs` — and like
the other two it carries no `description` field, so the two nodes that define every component's
public interface are undocumentable by any means the library has.
