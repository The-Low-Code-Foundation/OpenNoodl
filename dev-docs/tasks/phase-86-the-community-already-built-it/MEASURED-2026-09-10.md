### 4.1 The one that matters

```
ERROR [nonexistent-port] Dropzone › node open-file-picker (Open File Picker) › output "success":
  Open File Picker has no output named "success".
  → available: completed, done, error, failure, file, name, path, sizeInBytes, type, unchanged
```

🔴 **A community component shared for years wires a port that does not exist.** Checked against our
own shipped prefab: `library/prefabs/file-upload/project/project.json` wires the same node's `done`,
`error`, `failure`, `file`, `unchanged` — and no `success`. **The product is right and the community
graph is wrong** (or predates a rename). This is the phase's standing caution: circulation is not
verification.

### 4.2 The other three errors are one story

`unknown-node-type` on `module.inlineHtml` (×2) and `Markdown` (×1) — module-provided nodes the
built-in catalog cannot see. Expected, and *not* a defect: the accompanying
`unknown-type-check-skipped` info says so plainly. It does mean a graph depending on a module needs
a module-declaration story before it can be an example. COM-003 AC3.

### 4.3 The 33 spacing warnings are a look problem, not a wiring problem

Every one is `raw-spacing-literal` — `{"value":16,"unit":"px"}` where `var(--space-4)` is the same
value. The corpus predates the token scale. 🔴 **Landing these verbatim would seed the example
library with hardcoded px**, which is the P81 defect in the artefacts an agent imitates.

## 6. Traps found in session 1

- 🔴 **`wc -l` overstates the dictionary by 4×** — 404 lines, 94 records. Quoted CSV fields carry
  embedded newlines. Count with a CSV reader.
- 🔴 **A naive fence parse undercounts the graphs.** Matching only ```` ``` ```` finds 10; the corpus
  also uses ```` ```json ```` and ```` ```css ````. The real split is 12/14/3 and the first pass read
  10/19/0.
- ⚠️ **`timeout` does not exist on this box** (BSD userland). Don't reach for it.
- ⚠️ Piping `npm run` into `tail` hands you `tail`'s exit status. Both gate readings above were
  re-taken by redirecting to a file and reading `$?`.
